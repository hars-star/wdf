About StudentHub Project

StudentHub is developed as part of the curriculum for ITUE203: Web Development Frameworks at CHARUSAT. The platform provides an integrated academic interface for student profiles, event registrations, and administrative monitoring.

Responsive Architecture Highlights

CSS Grid

Utilized for 2-dimensional layouts, cards grid with repeat(auto-fit, minmax(...)), and multi-tier dashboard summaries.

CSS Flexbox

Implemented for 1-dimensional components like navigation bars, breadcrumbs, button clusters, and form row alignment.

Media Queries

Ensures clean adaptation across small mobile screens (<640px), tablets (768px-1024px), and ultra-wide desktops.
