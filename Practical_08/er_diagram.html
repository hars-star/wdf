StudentHub Normalized Relational Schema (ER Model)

3NF Normalized Relational Database Architecture on MySQL with Foreign Key Constraints & Triggers.

users
id (INT UNSIGNED) PK
name (VARCHAR 100) NOT NULL
username (VARCHAR 50) UNIQUE
email (VARCHAR 150) UNIQUE
mobile (VARCHAR 15) NOT NULL
password_hash (VARCHAR 255) BCRYPT
role (ENUM 'admin', 'student') DEFAULT 'student'
status (ENUM 'Active', 'Inactive') DEFAULT 'Active'
last_login (DATETIME) NULL
created_at (TIMESTAMP) CURRENT_TIMESTAMP
students
id (INT UNSIGNED) PK
user_id (INT UNSIGNED) FK -> users.id
enrollment_no (VARCHAR 20) UNIQUE
name (VARCHAR 100) NOT NULL
email (VARCHAR 150) UNIQUE
department (VARCHAR 50) NOT NULL
course (VARCHAR 50) NOT NULL
year (TINYINT) NOT NULL
gender (ENUM) NOT NULL
gpa (DECIMAL 3,2) 3.50
events
id (INT UNSIGNED) PK
title (VARCHAR 150) NOT NULL
description (TEXT) NOT NULL
category (VARCHAR 50) Technical / Workshop...
venue (VARCHAR 150) NOT NULL
event_date (DATE) NOT NULL
max_seats (INT) DEFAULT 100
registered_count (INT) DEFAULT 0
poster_file (VARCHAR 255) NULL
status (ENUM) Upcoming / Closed
registrations
id (INT UNSIGNED) PK
student_id (INT UNSIGNED) FK -> students.id
event_id (INT UNSIGNED) FK -> events.id
registration_date (TIMESTAMP) CURRENT_TIMESTAMP
status (ENUM) Confirmed / Waitlisted
remarks (VARCHAR 255) NULL
audit_logs
id (INT UNSIGNED) PK
user_id (INT UNSIGNED) FK -> users.id
username (VARCHAR 50) NOT NULL
action (VARCHAR 50) NOT NULL
entity (VARCHAR 50) NOT NULL
details (TEXT) NOT NULL
ip_address (VARCHAR 45) NOT NULL
created_at (TIMESTAMP) CURRENT_TIMESTAMP

Relational Cardinalities

  • users (1) ── (0..1) students: One user record optionally maps to one student profile.
  • students (1) ── (N) registrations: A student can register for multiple events.
  • events (1) ── (N) registrations: An event has multiple student registrations.
  • registrations has composite uniqueness constraint UNIQUE(student_id, event_id) preventing double-booking.
  • users (1) ── (N) audit_logs: System actions traceable back to triggering administrator/user.
